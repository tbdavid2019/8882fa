## 一、功能需求（Feature Requests）

### 高優先順序

#### 1. WebDAV / S3 加密備份到雲盤

- **提出者**: zhubaiwan-oozzxx (#51, #54), 952777 (#114), chuanqibuding (#115)
- **描述**: 多人反覆提出，認為資料只存在 CF KV 不夠安全，希望能定時備份到 WebDAV 或 S3 雲盤，支援加密
- **原始反饋**:
  - zhubaiwan-oozzxx: "能否 webdev 定時備份？"
  - zhubaiwan-oozzxx: "所有資料都儲存在 cf 也不算很安全，希望佬友能增加一個 webdev 備份"
  - 952777: "不懂就問，這種能做成連線webdav自動把加密過的資料備份到雲盤上嗎？"
  - chuanqibuding: "最好能夠webdav或S3加密備份"
- **參考**: ruchu8/2fa 已實現 GitHub Actions 版本的 S3/WebDAV/GitHub 多後端備份同步，但質量不高
- **狀態**: 待開發

#### 2. ~~修復模態框誤關閉 Bug~~ ✅ 已修復

- **提出者**: chuanqibuding (#101)
- **描述**: 手動新增金鑰時滑鼠不小心點到視窗外面，新增視窗就消失了，填寫的資料丟失
- **原始反饋**: "點選手動新增 滑鼠不小心點到外面 手動新增視窗就消失了。這個可以修復下嗎？"
- **狀態**: ✅ 已修復（`320b140` — 停用點選模態框外部關閉）

### 中優先順序

#### 3. ~~PC端截圖/貼上識別二維碼~~ ✅ 已實現

- **提出者**: chuanqibuding (#115, #116)
- **描述**: 方便電腦使用者，截圖或複製二維碼圖片後直接貼上識別
- **原始反饋**: "建議新增PC端截圖識別二維碼。方便電腦使用者。"
- **參考**: ruchu8/2fa 已有實現（handleGlobalPaste, triggerPasteQR, decodeQRCodeFromBlob），但程式碼質量不高，建議自行重新實現
- **狀態**: ✅ 已實現 — 掃碼彈窗和二維碼解析工具均支援剪貼簿貼上 + 拖拽圖片識別二維碼

#### 4. 登入支援 2FA 驗證 / 防爆破

- **提出者**: lewss (#82)
- **描述**: 擔心密碼被爆破，建議登入本身也支援 2FA 驗證
- **原始反饋**: "登入支援2fa嗎？密碼還是怕爆破。"
- **狀態**: 待評估（目前已有 rate limiting 5次/分鐘）

#### 5. 分類和收藏功能（常用金鑰置頂）

- **提出者**: kitwing (#53)
- **描述**: 金鑰多時需要分類管理，常用的可以置頂/收藏
- **原始反饋**: "佬，希望增加個分類和收藏（把常用的置頂）"
- **回覆**: 你(#122): "專案一開始只有我在用，因為我管理150+個金鑰...分類和收藏，包括置頂一開始就沒考慮過，後面我再認真想一下"
- **狀態**: 待開發

#### 6. 專案更新流程簡化

- **提出者**: kitwing (#53)
- **描述**: 使用者不太懂 CF 上怎麼更新版本
- **原始反饋**: "如果專案更新了，CF上怎麼更新，不太懂CF"
- **回覆**: 你(#122): "把workers專案刪除即可(KV千萬不要動)，然後重新一鍵部署"
- **狀態**: 可考慮提供一鍵更新方案或文件
